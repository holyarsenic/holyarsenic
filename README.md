## Selected Work

**[Void UI](https://github.com/holyarsenic/Void-AI)**
AI-powered UI generator. Describe an interface in plain words and get an animated component, built with Motion, in a live preview. Save generations to projects, pin favorites, and reopen them from history. Google sign-in with NextAuth, PostgreSQL with Prisma, Zod-validated APIs, and Dodo Payments billing.
*Next.js · Gemini · Prisma · Motion*

**[Shuriken](https://github.com/holyarsenic/Shuriken)**
Full-stack social web app for image discovery and community engagement, with protected routing, auth context, and push notifications.
*React · Node.js*

**[Themo](https://github.com/holyarsenic/Themo)**
Collection of dark themes for Visual Studio Code, from translucent glass looks to flat solid ones (Soft Hub, Chernobyl, Moth, Matrix). Every theme ships with customization examples for italics, comment contrast, and solid surfaces.
